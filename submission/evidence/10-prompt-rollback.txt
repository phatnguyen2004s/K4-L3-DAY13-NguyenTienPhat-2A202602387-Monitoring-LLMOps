# CP2 prompt promote/rollback — API chạy liên tục với LANGFUSE_PROMPT_LABEL=production, KHÔNG restart, không sửa code
# Cùng input cho mọi request. v1 -> tokens_in=32, v2 (prompt dài hơn) -> tokens_in=49.
# SDK cache prompt 60s kiểu stale-while-revalidate: request đầu sau khi hết TTL vẫn nhận bản cũ
# và kích hoạt refresh nền; request kế tiếp mới dùng version mới => độ trễ rollback ≈ TTL + 1 request.
